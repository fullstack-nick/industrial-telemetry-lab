# ADR 004: Deterministic observation identities

- Status: Accepted
- Date: 2026-08-29

## Context

Random IDs generated by a collector or worker change on retry and replay, so they cannot recognize the same source fact. Source sequences alone can reset after a process restart.

## Decision

Derive a SHA-256 observation ID from length-delimited facility ID, source system, process-lifetime source epoch, source sequence, and source tag. The simulator creates a new random epoch whenever its process starts; a sequence reset inside a new epoch is a new identity.

## Consequences

The same observation remains stable across batches, retries, consumers, and replay. A source that incorrectly reuses an epoch with different event time creates an explicit identity conflict. Source epoch is operational identity, while seeded measurement generation remains reproducible.

## Verification

Contract utility tests assert identity determinism and field sensitivity. Restart and duplicate scenarios assert persistence and uniqueness.
