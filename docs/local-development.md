# Local development

## Prerequisites

- Java 21 (the Maven Enforcer rule rejects other major versions)
- Docker Engine/Desktop with Compose v2
- Git
- PowerShell 7+ on Windows, or Bash 4+ with `curl`
- Approximately 4 CPU cores, 8 GiB memory, and 15 GiB free disk

Run the platform-specific prerequisite check before downloading images:

```powershell
Copy-Item .env.example .env
.\scripts\check-prerequisites.ps1
```

```bash
cp .env.example .env
./scripts/check-prerequisites.sh
```

The checked-in credentials are synthetic. Replace them on a shared host, but keep `.env` uncommitted.

## Build and start

Fast Java verification:

```powershell
.\mvnw.cmd --no-transfer-progress verify
```

Start core services only:

```powershell
docker compose up -d --build
```

Start core plus metrics, logs, traces, dashboards, and local alerts:

```powershell
docker compose --profile observability up -d --build
```

Compose runs database migration once before gateway and worker. Use `docker compose ps` until every long-running service is healthy. The application services still retry runtime dependency loss; Compose ordering is not treated as an availability guarantee.

## Useful commands

```powershell
# Follow structured application logs
docker compose logs -f controller-simulator edge-collector telemetry-gateway telemetry-worker

# Inspect a service health endpoint
Invoke-RestMethod http://localhost:8082/actuator/health

# Show collector durability state
Invoke-RestMethod http://localhost:8082/collector/v1/status

# Run all nine recovery and boundary scenarios
.\scripts\run-end-to-end-tests.ps1

# Verify code, Compose, dashboards, OpenAPI, and scenarios
.\scripts\verify-local.ps1

# Compare runtime OpenAPI without replacing the snapshot
.\scripts\verify-openapi.ps1

# Intentionally refresh the committed snapshot after review
.\scripts\export-openapi.ps1
```

The `.sh` scripts provide the same behavior on Bash.

## Profiles and state

Normal stop preserves named volumes:

```powershell
docker compose --profile observability down
```

The durable volumes hold PostgreSQL/TimescaleDB, RabbitMQ, SeaweedFS, SQLite/WAL, Grafana, Prometheus, Loki, and Tempo state. `scripts/reset-local-data.ps1` (or `.sh --force`) is intentionally destructive: it resolves the current Compose project, prints the exact matching volume names, asks for confirmation, and removes only those volumes.

Never manually remove broad Docker data directories. If a scenario is interrupted, first restore services with:

```powershell
docker compose start controller-simulator telemetry-gateway telemetry-worker timescaledb seaweedfs rabbitmq
docker compose up -d edge-collector
```

## Contract workflow

1. Add a new schema/mapping/rules version; do not edit existing semantics.
2. Add contract examples and tests.
3. Change implementation and bounded failure assertions.
4. Start the gateway and run `scripts/export-openapi.*` only if the reviewed HTTP contract intentionally changed.
5. Run `verify-local`.

The OpenAPI snapshot is generated by the running application, normalized, and compared. An unexplained diff is a contract failure.

## Troubleshooting

### A port is occupied

The prerequisite check lists the process or container using required ports. Stop that project or explicitly change every corresponding Compose and documentation value. Do not publish a data port on all interfaces.

### Docker reports unhealthy dependencies

Use `docker compose ps` and inspect the dependency's own logs. First image pulls and TimescaleDB initialization may take several minutes. The migration container must exit with code zero.

### The collector spool does not drain

Check collector status, gateway health, PostgreSQL/SeaweedFS health, and the collector log in that order. Use `docs/runbooks/collector-offline.md`; do not delete the SQLite volume.

### RabbitMQ grows after the worker returns

Confirm the worker is healthy, then distinguish database failures from processing errors with `docs/runbooks/pipeline-backlog.md`. A permanent DLQ message is not automatically discarded.

### A simulator cursor is gone

The collector deliberately stops that source. Inspect `gapDetected` and `gapDetail`; understand the missing sequence range before invoking the authenticated `/collector/v1/gap/recover` endpoint. Recovery is an explicit acceptance of a data gap.

### Windows shell details

Use PowerShell scripts natively. Bash scripts are tested for syntax under WSL2; keep LF line endings and executable bits when changing them. The Maven Wrapper selects Maven 3.9.16 on both paths.
